# Mash documents

Prose for mash regimes, wort fermentability, and the yeast/style relationship.
`data/artifact.json` and [`../attenuation-model.md`](../attenuation-model.md)
own the model; these documents explain and annotate.

| Document | Status | Scope |
| --- | --- | --- |
| [`reference/mash-regimes-fermentability-styles-and-yeasts.md`](reference/mash-regimes-fermentability-styles-and-yeasts.md) | background | generated conversation on the two-lever model — mash regime → sugar spectrum → yeast sugar uptake → style strategy — and the source material for the mash/yeast/style critiquer |

Background documents are imported verbatim and are not maintained here. Where a
background document disagrees with the attenuation model or with
`data/artifact.json`, the artifact wins. Corrections belong in a living
document, not in the transcript.

The living contract for attenuation is [`../attenuation-model.md`](../attenuation-model.md);
the critiquer contract is [`../../plans/recipe-critiquers.md`](../../plans/recipe-critiquers.md).
